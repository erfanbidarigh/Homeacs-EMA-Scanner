# اسکنر EMA هومکس — پروژه اندروید

این پروژه سورس اپلیکیشن Android Studio است؛ APK آماده در این بسته ساخته نشده است.

## قابلیت‌ها

- اسکن بازار عمومی Bitunix Futures
- فیلتر حجم ۲۴ ساعته: بیشتر از ۲۰۰ BTC معادل
- روند صعودی: EMA50 > EMA200 در هر دو تایم‌فریم 1h و 15m
- روند نزولی: EMA50 < EMA200 در هر دو تایم‌فریم 1h و 15m
- هشدار نزدیک‌شدن قیمت آخرین معامله به EMA200 تایم‌فریم 15m
- اعلان اندروید و اجرای اسکن در Foreground Service
- جلوگیری از هشدار تکراری تا زمانی که قیمت از محدوده EMA دور شود
- فاصله اسکن: ۳۰ ثانیه پس از پایان هر دور؛ اگر تعداد نمادهای واجد شرایط زیاد باشد، هر دور بیشتر طول می‌کشد.

## روش محاسبه حجم

مقدار `quoteVol` (گردش به ارز مظنه، معمولاً USDT) تقسیم بر قیمت BTCUSDT؛ مقدار حاصل، معادل تقریبی BTC است.

## روش تشخیص برخورد

REST API تیکر Bitunix هر دور اسکن خوانده می‌شود. اگر قیمت آخرین معامله در فاصله تنظیم‌شده از EMA200 پانزده‌دقیقه‌ای باشد، هشدار صادر می‌شود. مقدار پیش‌فرض فاصله ۰٫۱۵٪ است و در صفحه برنامه قابل تغییر است. چون از polling استفاده می‌شود، لمس کوتاه قیمت بین دو درخواست ممکن است از دست برود؛ برای تشخیص پیوسته‌تر می‌توان WebSocket عمومی قیمت را اضافه کرد.

## ساخت APK در Windows

1. Android Studio را نصب کن.
2. پوشه `HomeacsEmaScanner` را با گزینه **Open** باز کن.
3. Android SDK Platform 35 و Android Build Tools موردنیاز را نصب کن.
4. صبر کن Gradle Sync کامل شود.
5. از منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیر.
6. APK در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## نصب و اجرا

1. APK را روی گوشی نصب کن.
2. برنامه را باز کن و اجازه Notifications را بده.
3. حداقل حجم را روی ۲۰۰ BTC بگذار.
4. فاصله قیمت تا EMA را روی ۰٫۱۵٪ نگه دار یا مطابق نیاز تغییر بده.
5. «شروع اسکن پس‌زمینه» را بزن.
6. اعلان دائمی «اسکنر EMA هومکس» باید در نوار اعلان‌ها دیده شود.
7. برای توقف، وارد برنامه شو و «توقف اسکن» را بزن.

در گوشی‌هایی که مدیریت باتری تهاجمی دارند، برنامه را از Battery Optimization خارج کن. Force Stop کردن برنامه توسط کاربر، اجرای سرویس را متوقف می‌کند.

## API مورد استفاده

- Bitunix Futures Tickers: https://www.bitunix.com/api-docs/futures/market/get_tickers.html
- Bitunix Futures Kline: https://www.bitunix.com/api-docs/futures/market/get_kline

## پارامترها

- EMA سریع: ۵۰
- EMA کند: ۲۰۰
- تایم‌فریم روند: 1h و 15m
- حداقل حجم: ۲۰۰ BTC معادل
- فاصله هشدار از EMA200: پیش‌فرض ۰٫۱۵٪
- فاصله اسکن: ۳۰ ثانیه پس از پایان اسکن قبلی
- جهت‌ها: LONG و SHORT

این برنامه فقط هشدار می‌دهد و هیچ سفارش یا معامله‌ای ثبت نمی‌کند.

## ساخت APK بدون نصب SDK روی ویندوز (با GitHub Actions)

در ریشه مخزن GitHub، پروژه را با همین ساختار بارگذاری کن. فایل workflow در مسیر `.github/workflows/build-apk.yml` قرار دارد. پس از push روی شاخه `main`، وارد تب Actions شو، اجرای `Build Android APK` را باز کن و پس از موفقیت، از بخش Artifacts فایل `Homeacs-EMA-Scanner-debug-apk` را دانلود کن. فایل داخل ZIP، `app-debug.apk` است.
